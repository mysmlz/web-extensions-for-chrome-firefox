# BlingBling

### 简介

对bilibili网页端的优化.

### 功能

1. 去除广告(及被Adblock Plus等插件屏蔽的广告)
2. 去除上方大型轮播(可选)
3. 暗色模式(`Doing`,可选)
4. 去除直播、番剧、综艺等卡片推荐(`TODO`,可选)
5. 去除较旧的视频(可设置间隔时间)(`TODO`,可选)
6. 去除最上方Adblock Plus等插件屏蔽提醒(`TODO`)
7. 优化头部菜单(`TODO`)
8. 优化次头部菜单(`TODO`)
9. 去除大会员按钮(`TODO`,可选)
10. 去除创作中心和投稿(`TODO`,可选)
11. 优化视频页(`TODO`)
12. 优化专栏页(`TODO`)
13. 优化直播页(`TODO`,低优先级)
14. …
