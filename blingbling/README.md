# BlingBling

### 简介

对bilibili网页端的优化.

### 功能

1. 去除广告(及被Adblock Plus等插件屏蔽的广告)
2. 去除上方大型轮播
3. 暗色模式(`Doing`,可选)
4. 去除直播、番剧、综艺等卡片推荐(可选)
5. 去除最上方Adblock Plus等插件屏蔽提醒
6. 优化头部菜单(`TODO`)
7. 优化次头部菜单(`TODO`)
8. 去除大会员按钮(可选)
9. 去除创作中心和投稿(可选)
10. 优化视频页(`TODO`)
11. 优化专栏页(`TODO`)
12. 优化直播页(`TODO`,低优先级)
13. 无"充电"按钮时,延长"关注"按钮,使其更美观
14. 去除直播卡片(可选)
15. 创始用户颜色的用户名(可选)
16. 合集默认显示更多的视频
17. 去除视频播放页的弹幕列表(可选)
18. ...
